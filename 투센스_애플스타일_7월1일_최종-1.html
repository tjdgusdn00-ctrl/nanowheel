정산관리

판매내역 업로드 시 주문번호 기준으로 정산예정금액이 생성됩니다. 정산파일 업로드 시 주문번호로 자동 매칭되고, 부분정산/중복정산/미매칭/초과정산을 자동 표시합니다.

정산파일 업로드

정산완료일은 파일 안 날짜보다 위에서 선택한 반영 기준일을 우선 적용합니다. 단, 쿠팡 일반은 정산파일의 구매확정일/정산예정일을 읽고 1차 70%, 2차/30% 파일은 잔여 30%로 반영합니다. 파일명에 30%/2차/잔여가 있으면 파일 내 예정일이 과거 1차 예정일로 표시되어도 상단 반영기준일의 2차 정산으로 처리합니다. 쿠팡 그로스는 별도 판매처로 분리하여 쿠팡 일반 판매건과 섞이지 않게 매칭합니다. 정산관리 업로드는 현금을 증가시키지 않으며, 현금 증가는 입금현황 탭 정산입금에서만 반영됩니다. 오프라인 판매는 판매현황 업로드 시 정산완료 원장이 자동 생성됩니다. 중복등록 방지 기준: 판매처 + 상품주문번호 + 주문번호 + 정산일 + 정산금액 + 정산차수 + 거래ID. 같은 파일을 다시 올려도 이미 반영된 정산자료는 중복 제외됩니다. 알리 정산은 같은 주문번호의 판매금액/수수료 행을 묶어 순정산액 1건으로 반영하고, 음수 수수료는 판매건 수수료에 자동 반영합니다.

조회기간 판매내역을 보면서 실제 배송비를 입력합니다. 저장하면 판매건과 매칭된 광고 소재ID별 배송비 합계가 PC/모바일 광고효율표의 배송비에 자동 반영됩니다. 수량을 같이 표시해 묶음배송·복수수량 확인이 가능합니다.
